# Juego-Meteoros-Firebase
Este proyecto consiste en un videojuego de supervivencia con mecánicas simples: el objetivo es resistir el mayor tiempo posible sin ser alcanzado por un meteorito. Cuando el jugador pierde, su puntuación se registra automáticamente en Firebase y se muestra en una tabla clasificatoria en tiempo real, fomentando la competencia y la mejora continua.
